# 电量与费用定义

id为计量号、order为订单号、station为站点，均为字符串。kind取order或station。计量start/end必须带时区，区间[start,end)，最大72小时可调至168小时。energy以kWh或MWh输入，输出kWh。未知哨兵不等于零。
费率版本以本地+08日期[from,to)生效；日内时段必须完整无重叠覆盖0–24小时。默认11月17日调整尖峰价，可在API参数tariffs中提供相同结构版本清单。
计量段内假定匀速用电，电量按时长交集分配，最后一段修正Decimal除法尾数保证电量严格守恒。跨日以当地日期重选版本。
每站唯一总表电量减订单电量为损耗，按订单kWh占比分配。总表缺失、重复、负损耗或无订单承接损耗时标记异常，不强行分配。
订单应收=各分时电量×费率+损耗份额×loss_rate。先算站总额再最大余额分币，稳定id打破余数并列。JSON金额为Decimal字符串。账单bill为CNY，差额=应收-bill，容差边界包含。
版本最高者采信，同版冲突全部隔离；重复和旧版计入隔离。输入行数=采信+隔离。批次哈希包含输入摘要、规则版本、参数；复核乐观锁防止旧提交覆盖。

站点总表区间必须覆盖其全部订单区间；未覆盖标记总表未覆盖订单区间，损耗不强制分摊，账单结论为待复核。

站点拆分：拆分日按本地+08日期界定，当日订单与总表仍可写旧站名，已复核批次保持原样可查。每个新运营区登记一张总表，各总表区间必须恰好首尾相接覆盖拆分日00:00–24:00，缺口报GAP、重叠报OVERLAP、未恰好覆盖报RANGE；旧站当日其余总表未指定承接区报CONFLICT。订单按计量段匀速假定以时间交集分配到段并末段修正守恒，跨段订单被精确切开；段损耗=段总表−段订单，归属该运营区，负损耗或无订单承接仅标记不强行分摊。损耗金额按loss_rate以分结算，跨区尾差按最大余额法分配、区名稳定打破并列。承接结果以输入摘要、站点、拆分日、运营区映射与规则版本哈希为唯一标识；同一(站点,拆分日)仅允许一条生效承接，相同请求幂等返回既有记录（含已回滚状态），修正数据后重新执行生成新记录。执行先计算后原子落库，失败不留半条记录；回滚恢复旧版本并保留原记录，当日随即允许重新拆分。
